项目介绍

「我的个人知识库」是一个面向网络与新媒体（智能传播）专业的个人学习档案网站。 它把一年来的课堂笔记、交互设计方法、前端实践记录与竞赛实训经验，按四大分类重新组织， 并提供笔记检索与专业教材知识点检索两条查找路径。

网站的定位是「可用的复习工具」而不只是展示页面：所有内容的数据结构统一， 搜索会同时匹配标题、标签、简介与正文，教材检索可以按书目、章节、关键词三层定位， 并且每条知识点都能跳转到相关笔记。

设计思路

01

先定信息结构，再谈视觉

用「首页门户 → 分类 → 列表 → 详情」的层级组织内容，保证任意内容三步内可达。导航固定为五个入口，不增加用户的记忆负担。

02

低饱和度的单主色体系

主色浅蓝 #409EFF 承担交互与强调，浅绿 #67C23A 只用于「更新/成功」语义，浅橙 #E6A23C 用于标签。四类知识用同色系的深浅区分，避免页面出现过多颜色。

03

卡片 + 留白的模块化版式

所有内容区块统一为 8px 圆角的卡片，模块间距 24–32px，字号只用 12/14/18/24 四档，形成清晰的视觉层级。

04

克制的动效

统一的 0.3s 缓动过渡；hover 时卡片上浮 8px、阴影加深、轻微放大到 1.03 倍；按钮按下时缩小到 0.95 倍作为点击反馈。动效只说明「可交互」与「层级关系」，不做额外装饰。

05

移动端重新排布而非压缩

768px 以下全部转为单列，导航折叠为汉堡菜单，工具栏改为纵向堆叠，保证触控目标不小于 44px。

技术栈

H5

HTML5 语义化标签

header / nav / main / section / footer 结构

CSS

CSS3 + 变量系统

Grid / Flex、自定义属性、过渡与动画

JS

原生 JavaScript

数据渲染、搜索打分、IntersectionObserver

RWD

响应式设计

媒体查询 + 流式布局，断点 768 / 1024

全站为纯静态页面，无框架、无外部依赖、无网络请求。内容以 JavaScript 数组形式集中管理（data.js / books.js）， 新增笔记只需在数组中追加一条对象，列表页、搜索、分类页与首页会同步更新。

学习感悟

做这个网站之前，我的笔记散落在备忘录、课程群和本地文档里，找一条内容往往要翻很久。 整理成结构化的知识库之后我才发现，真正的难点不是写笔记，而是分类—— 一条关于「算法推荐」的记录，到底属于传播理论还是技术实践？后来我接受了一件事： 归档的目的不是唯一正确，而是下次能找到。

「交互设计不只是让东西变好看，而是让人的意图和系统的反馈之间，少绕几步路。」

这门课里对我影响最大的是「可用性原则」和「示能」这两组概念。它们让我意识到， 那些我以为理所当然的按钮、提示、加载动画，其实都是设计者替用户提前想好的。 现在我做作业时会习惯性地问自己三个问题：用户到这里知道下一步做什么吗？操作有反馈吗？ 出错了他能自己救回来吗？

这个知识库还会继续更新。下一步打算补充「智能传播」方向的内容：推荐系统的基本原理、 生成式 AI 对内容生产流程的影响，以及算法伦理相关的公开讨论案例。
